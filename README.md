# LOL : AFTER DARK 💋

처음 접속하면 **"혼자 있을 때 진행하세요"** 경고 팝업이 뜨고 확인 버튼을 누르면 테스트할 수 있습니다. 만 19세 이상을 위한 비공식 롤 챔피언 이상형 팬메이드 테스트. 10문항, 여성/남성/모두 선택, 챔피언 TOP 5, 결과 이미지 PNG 저장, 링크 공유.

## 맥북에서 미리보기

`index.html`을 Safari 또는 Chrome에서 더블클릭하면 열립니다. 매칭 후보 28명 전원의 기본 일러스트를 Riot Data Dragon CDN에서 표시하도록 연결해 두었습니다. 이미지 파일이 ZIP에 내장된 것은 아니므로 인터넷 연결이 필요합니다. 이미지를 불러오지 못해도 테스트와 결과는 계속 작동합니다.

## GitHub Pages에 무료 공개하기

1. GitHub에서 **새 공개 저장소**를 만듭니다. 예: `lol-after-dark`.
2. `index.html` **한 파일을** 저장소의 최상위 위치에 업로드하고 Commit changes를 누릅니다. ZIP 파일 자체를 올리지 마세요.
3. 저장소의 **Settings → Pages**를 엽니다.
4. **Source: Deploy from a branch / Branch: main / Folder: / (root)** 로 정한 뒤 Save를 누릅니다.
5. GitHub Actions/Pages 배포가 완료되면 `https://본인아이디.github.io/lol-after-dark/`로 접속하세요. 새 웹주소가 반영되려면 몇 분 걸릴 수 있습니다.
6. 결과 링크 공유는 GitHub Pages 같은 공개 주소에서 작동합니다. 로컬 파일(`file://`)로 열 때는 링크 공유가 지원되지 않습니다.

## 사용법

- 10문항에 답하거나 PC에서 A~E 단축키로 선택할 수 있습니다.
- 결과 카드 저장 버튼은 PNG를 생성합니다.
- 공유 버튼은 `?r=` 파라미터에 답변을 담아 링크를 만들기 때문에 **결과를 공유하면 선택 정보가 URL에 포함됩니다**. 별도 답변 데이터베이스는 운영하지 않지만, 공유 링크를 본 사람이나 호스팅 서비스가 URL을 볼 수 있으므로 민감한 답변은 링크로 공유하지 않도록 주의하세요. 링크를 전달받은 사람은 결과를 볼 수 있습니다.
- `index.html` 한 파일만 수정해도 디자인, 질문, 챔피언 추천을 바꿀 수 있습니다.

## 안내

Riot Games와 관계없는 비공식 팬 창작물입니다. 챔피언 이미지 및 이름의 권리는 권리자에게 있습니다. 성인이고 인지적 의사소통이 가능한 판타지/의인화 캐릭터만 대상으로 하며 실제 동물은 포함하지 않습니다. 성향 점수는 오락 목적입니다.
